# CFLark · 沉浸光感与视觉体系约定

> 适用：`entry/src/main/ets/pages/Index.ets`（当前全部 UI 都在这个文件里）
> 目标 SDK：API 26（`build-profile.json5` → `targetSdkVersion: '26.0.0'`）
> 配套通用知识：全局技能 `harmonyos-immersive-material`

---

## 0. 一句话前提

**内容区的 `systemMaterial` 不会被渲染。**
真机日志：`Material inactive: out of scope. Use component in navigation title bar or Tabbar.`

所以本工程的约定是：

| 表面 | 技术 |
| --- | --- |
| 内容卡片 / 自绘胶囊 | 官方 `backgroundBlurStyle` + `linearGradient` + 描边 + 投影（手绘玻璃，见 §3） |
| 底部悬浮 TabBar | `Tabs` + `barPosition: End` + `barOverlap` + `barFloatingStyle`（系统沉浸光感，见 §4） |
| 弹窗 / 半模态 / 菜单 | `module.json5` 的 `ohos.arkui.UIMaterial.state = enable` 自带材质 |
| 标题栏联动 | `HdsNavigation.titleBar.style.systemMaterialEffect` |

**不要**再给内容区卡片加 `Toggle` 承载层。`MatStore / GlassCarrierModifier / GlassCarrier / GlassBackdrop`（`Index.ets:60 / 109 / 136 / 2105`）是当年的实验产物，当前**无调用点**，保留只为记录结论，新代码别引用。

## 1. 状态与判定链（唯一真源）

```
@State globalImmersion : boolean    // 设置页「全局沉浸光感」总开关
@State matType         : number     // 0 自适应 / 1 沉浸 / 2 无材质
@State matLevel        : number     // 0 自适应 / 1 精致 / 2 柔和 / 3 平滑
        ↓
matSupported()          = uiMaterial.isImmersiveMaterialSupported()
shouldUseCardMaterial() = globalImmersion && matType !== 2 && matSupported()
effLevel()              = -1 关闭 | 0 厚 | 1 中 | 2 薄   ← 所有视觉都从它派生
        ↓
cardBlurStyle() / cardTint() / cardBorderColor() / cardShadowR/Y/Color() / navGlassStyle()
hdsMatType()   ← 关闭或不支持时返回 MaterialType.NONE（否则底部 TabBar 会残留材质）
```

**约定**：任何与材质相关的新视觉，都必须从 `effLevel()` 或 `shouldUseCardMaterial()` 派生，**不要**在组件里直接读 `globalImmersion`。

`effLevel()` 语义：

- `< 0`：材质关闭 → 模糊 `NONE`、实心底、弱描边、4vp 小投影（另一套完整设计，不是"同款卡片变淡"）；
- `0 / 1 / 2`：厚 / 中 / 薄玻璃 → `BACKGROUND_THICK|REGULAR|THIN`（`matType === 1` 时整体上调一档）；
- `matLevel === 0`（自适应）时读 `uiMaterial.getGlobalMaterialLevel()`：`EXQUISITE → 0`、`GENTLE → 1`、`SMOOTH → 2`。

## 2. 背景层

`build()` 里 `bgPath` 为空时：渐变底色 → `AuroraLayer()`（`Index.ets:2139`）。

```ts
@Builder AuroraLayer() {
  Stack({ alignContent: Alignment.TopStart }) {
    Circle().width(this.winW * 1.20).height(this.winW * 1.20)
      .radialGradient({ center: [...], radius: ..., colors: [[theme, 0.34], [themeLow, 0.42], [transparent, 1.0]] })
      .position({ x: -this.winW * 0.46, y: -this.winW * 0.34 })
      .fill(Color.Transparent)      // ★ 必须，否则 Shape 默认黑填充盖住渐变
    // + #5B7CFA 右中、#2DD4BF 左下
  }
  .width('100%').height('100%')
  .hitTestBehavior(HitTestMode.None)
  .expandSafeArea([SafeAreaType.SYSTEM], [SafeAreaEdge.TOP, SafeAreaEdge.BOTTOM])
}
```

- 深色 alpha 0.34 / 0.30 / 0.20，浅色 0.26 / 0.20 / 0.16；主题色用 `accentRgba(alpha)`，固定色用 `hueRgba(hex, alpha)`；
- 尺寸和位置全部按 `winW / winH` 计算 → 手机 / 平板 / 窗口缩放自适应；
- 光斑是玻璃的"食材"：纯黑背景上做玻璃必然看不出效果。

## 3. 加一张玻璃卡片（模板）

```ts
@Builder CardXxx() {
  Stack({ alignContent: Alignment.TopStart }) {
    Column() {
      this.CardTitle('标题', $r('sys.symbol.xxx'))
      // 内容…（12/14vp 行距，说明文字 11vp 且只在需要时展示）
    }
    .width('100%')
    .alignItems(HorizontalAlign.Start)
    .padding(16)
    .onAreaChange((_o: Area, a: Area) => this.updateMeasuredCardHeight('xxx', a))   // 需要时才加
  }
  .width('100%')
  .backgroundBlurStyle(this.cardBlurStyle(), {
    colorMode: this.dark ? ThemeColorMode.DARK : ThemeColorMode.LIGHT
  })
  .linearGradient({ angle: 145, colors: this.cardTint() })
  .borderRadius(20)
  .border({ width: 1, color: this.cardBorderColor() })
  .shadow({ radius: this.cardShadowR(), color: this.cardShadowColor(), offsetY: this.cardShadowY() })
  .margin({ bottom: 12 })
}
```

硬性约定：

1. 圆角 `20`、卡间距 `12`、内边距 `16`、描边 `1vp`（关闭态也保持 1vp，不要用 0.5 造成不一致）；
2. 颜色 / 模糊 / 描边 / 投影**一律**走 helper，禁止硬编码；
3. 卡片内部**不要再叠** `.backgroundColor()`，需要层次用 `soft()` / `inputBg()` 的小块；
4. 不要在同一个 Stack 上同时挂 `backgroundBlurStyle` 和接近不透明的 `linearGradient`——会互相稀释；
5. 文字色只用 `txt() / txt2() / txt3()`，主题色文字用 `accentText()`，主题色填充用 `accentFill()`。

## 4. 底部悬浮导航

结构（`Index.ets:1860` 附近）：`Tabs` 四页 + `.barPosition(BarPosition.End)` + `.barOverlap(true)` + `.barFloatingStyle(this.navFloatStyle())`，页签用 `@Builder TabItem(label, index)`（`:3462`）。

- 选中态：`TabItem` 内 icon/label 用 `this.accentText()`，并加淡色圆角底（`soft()` + `borderRadius(14)`）强化；
- **不要**换成自绘 `Stack + Row` 胶囊——那属于内容区，拿不到系统材质；
- `BottomNav()` / `NavItem()`（`:3131 / 3274`）是早期自绘版本，已不在主路径，改动前先 `grep` 调用点；
- 关闭材质时由 `navGlassStyle() → BlurStyle.NONE` 与 `hdsMatType() → NONE` 一起降级，不要只关一半。

## 5. 控件令牌与布局约定

`Index.ets:3770` 起：

```ts
private readonly CHIP_H: number = 34;   // chip 高度
private readonly CHIP_R: number = 9;    // chip 圆角
private readonly CHIP_FS: number = 12;  // chip 字号
private readonly BTN_H: number = 38;    // 按钮高度
```

复用 Builder：

| Builder | 位置 | 用途 |
| --- | --- | --- |
| `CardTitle(title, icon)` | `:3734` | 卡片标题（SymbolGlyph 16 + Text 15 Medium） |
| `FieldRow(label, value, onChange)` | `:3749` | 传统 label + 40 高输入框（新代码尽量不用） |
| `SegRow(label, items, current, onPick)` | `:3775` | 传统分段选择 |
| `ParamCell(label, value, inputId, numeric, onChange)` | `:3981` | **紧凑参数格**：12vp 标签压在上方 + 38 高输入框 + `layoutWeight(1)`，配合 `Row({space:10})` 做 2 列 / 4 列网格 |
| `AdvRow(open, onTap)` | `:4004` | 「高级选项 … 展开 / 收起」行（38 高、`soft()` 底） |
| `ParamNotes()` | `:4024` | 展开后显示的说明合集（11vp） |
| `EtFieldRow(...)` | `:5116` | 设置页紧凑输入行（label 90 宽） |
| `EtModeChip / EtPosChip / EtTopChip / EtWayChip` | `:5140` 起 | 设置页双 / 三 chip 组 |

**布局约定**：低频参数默认收进 `AdvRow` 折叠；核心参数（扫描模式、来源、IP 版本、端口、节点数量、阈值）必须常显；说明文字不要一行一段，合并进折叠区或压成单行。

⚠️ `GridRow` 不带 `breakpoints` 时会**静默丢弃溢出行**——用 `Row + layoutWeight` 代替，除非确实需要 GridRow 的断点表格。

## 6. 深浅色与对比度

| helper | 作用 |
| --- | --- |
| `accent()` | 原始主题色（渐变、进度条等大色块） |
| `accentFill()` | 深色 = accent；浅色 = 各通道 ×0.84 → 白字在浅粉 / 浅黄上可读 |
| `accentText()` | 深色 = accent；浅色 = ×0.62 → 图标 / 文字 |
| `accentPale() / accentSoft()` | 极淡底纹，仅用于装饰层 |
| `txt() / txt2() / txt3()` | 主 / 次 / 辅助文字；`txt3()` 浅色为 `#64748B` |
| `soft() / inputBg()` | 06 / 04 透明度的填充底 |

- 彩色背景上的文字用**主题无关纯白** `#FFFFFFFF`，不要用会随主题翻转的 inverse 色；
- 新增颜色前先在这几个 helper 里找，找不到再加，不要就地写 hex。

**材质开关回归**（每次动材质相关代码都要做）：

1. 设置 → 材质 → 关闭总开关 → 截图：卡片实底、无模糊、底部导航变实心、状态行显示「卡片（无材质）」；

## 8. 已知限制 / 待办

- `CustomImportDialog` 走 `CustomDialogController`，不支持系统材质。要玻璃需改成
  `promptAction.openCustomDialog({ builder, systemMaterial })`（行为改动，需确认后再做）。
- 筛选页 / 测速页内容较短时，`Scroll` 内容垂直居中（改动前既有表现，未处理）。
- 真机（非模拟器）在 `EXQUISITE` 等级下的长列表滚动帧率与发热未测。
- 若后续拆分 `Index.ets`，建议按 `ui/GlassTokens.ets`（颜色 / 圆角 / 间距）、`ui/GlassSurface.ets`（卡片表面链）、`ui/SettingWidgets.ets`（设置行 / 折叠组）三块迁；helper 目前都是 `Index` 的私有方法，迁移时保持同名以免大面积改调用点。
