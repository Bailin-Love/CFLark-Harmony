# CFLark v1.4.2 更新说明

- 版本号：1.4.2（versionCode 1004002）
- 日期：2026-10-30
- 状态：已发布（tag `v1.4.2`，Release: https://github.com/Bailin-Love/CFLark-Harmony/releases/tag/v1.4.2）
- 基线：v1.4.1

## 面向用户的变化（相对 1.4.1）

### 新增

1. **候选来源自定义分组**：一个分组可混放链接、文件、粘贴文本；链接来源支持一键更新；官方 IP 段与社区段库始终只读。
2. **IPv4 / IPv6 两套来源**：来源数据、启用状态、筛选输入各自独立；导入按当前 IP 版本校验，类型不符会给出原因；旧版自定义导入自动迁移，无法识别的行单独隔离。
3. **外观与主题合并**：跟随系统 / 深色 / 浅色、6 种主题色、9 格背景（无 + 7 张预设 + 自定义）；浅色与深色各自保存背景；跟随系统真实跟随设备。
4. **背景与玻璃可调**：背景模糊、背景明亮、背景遮罩，新增「卡片通透度」；遮罩拉到 0 就是完全不遮（与 1.4.1 观感一致），卡片通透度保留上下限（最透约基准的 0.56 倍、最实约 1.3 倍），避免调花到看不清。顶部的模糊淡出带与底部导航不受遮罩影响。
5. **说明入口统一**：7 个「ⓘ」共用同一弹窗，中英双语、可滚动，点遮罩 / 「知道了」/ 返回键均可关闭。

### 优化

1. **平板与电脑**：扫描页左右两列四卡；设置页左菜单 + 右内容（默认「订阅与上传」）；来源管理为居中玻璃面板；窄窗口自动退回单列。
2. **三页进度条统一**：扫描 / 筛选 / 测速各自卡片内常显阶段、已完成与百分比，停止后显示「已停止」。
3. **来源管理卡面化**：分组与来源改为玻璃卡片列表，与主页面材质一致。
4. **地区分组列独立**：筛选页展开一张地区卡只影响同列下方卡片。
5. **测速参数常显**：移除下载测速开关。
6. **代码清理**：移除旧工具栏、旧底部导航、旧材质承载层等零调用代码（Index.ets 9314 → 约 9060 行）。

### 修复

1. 浅色主题 + 深色壁纸时标题与文字看不清；切换深浅色后状态栏图标与窗口底色不跟随。
2. 裸 IPv6 地址（如 `2606:4700::1`）被当作「地址:端口」拆开，节点静默丢失。
3. 扫描 / 预检 / 测速共用一个运行状态，导致停止按钮与进度条串台。
4. 平板 / 电脑点「查看完整日志」无反应（宽屏未切到更新日志面板）。
5. 改完参数后立刻退出，最后一次修改可能丢失（退出时补一次落盘）。
6. 背景图读取失败会清空已保存的背景 → 现改为本次运行临时回退，不改设置。
7. 切换 IPv4 / IPv6 后残留上一种的结果与预检状态。
8. 帮助弹窗在短屏 / 横屏可能截断「知道了」。
