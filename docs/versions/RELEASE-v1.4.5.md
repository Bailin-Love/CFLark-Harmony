# CFLark v1.4.5 更新说明

- 版本号：1.4.5（versionCode 1004005）
- 应用包名：`com.bailin.cflark`
- 日期：2026-11-14
- 基线：v1.4.3（没有 1.4.4）
- 应用内更新说明：`entry/src/main/ets/core/Changelog.ets` 的 1.4.5 条目（中英双语）

## 面向用户的变化（相对 1.4.3）

### 新增

1. **多轮测速与单节点复测**：把「每地址次数」设为 2 或 3，结果卡展开后显示逐轮表格（轮次、延迟、连接、速度与当轮结果），失败轮写明原因。每张卡可单独复测，只测该节点，不影响其它结果，也不写入历史。
2. **历史记录（第 5 个页签）**：每次完整测速自动存一份快照（时间、参数、逐轮数据、排名），重启后仍在；点记录看节点，点节点看逐轮；详情页可删单条，列表可清空；保存上限可选关闭 / 30 / 50 条。
3. **历史走势双图**：历史页顶部两张走势图，延迟与速度各自独立刻度与时间轴，取每次记录的第 1 名节点，最新值直接标在最后一个点旁。
4. **完整 TXT 报告与 28 列 CSV**：TXT 分测速概况、节点统计表、逐轮明细、可复制地址四段；CSV 补有效速度、逐轮速度与结果、稳定性与三项评分，中文表头，Excel 打开不乱码。
5. **三维评分**：综合评分改为延迟、稳定性、速度三项；单轮看延迟与速度，轮数越多稳定性权重越大（三轮及以上占两成）；稳定性只计每轮测速时目标能否连上，429 或没下到数据这类下载失败不算连接失败。

### 优化

1. **多轮卡片更紧凑、平板两列独立**：多轮卡只留三行关键信息；平板两列各自流动，展开一张卡不再拉高邻列。
2. **「丢包」改称「连接失败」**：卡片显示连接失败百分比，逐轮表用「连接」列，筛选页叫「连接失败率上限」，默认 0%（一次探测失败即淘汰），100% 等于关闭该筛选。
3. **Ping 超时可调、默认参数更新**：Ping 超时 300–10000 ms（默认 1000 ms，只影响 TCP 建连）；新装默认 Ping 3 次、延迟上限 320 ms，首轮稍慢但延迟与连接失败率更可信。
4. **域名检测改为可选**：默认关闭；打开并填有效域名才在正式测速前逐个验证入选节点；下载测速固定走 speed.cloudflare.com，自定义域名不能下载时不再误判。
5. **只看达标**：测速页新增开关与「已达标 N/M」计数，只影响显示，评分、排序与导出不变。
6. **订阅上传排序**：同一地区内固定 IPv4 排在 IPv6 之前，追加内容同样重排，自定义行与订阅链接原样保留。

### 修复

1. **IPv6 Ping 次数与延迟门槛**：删掉「首包够快就提前结束」，按设定次数测完（首次连接超时仍提前结束）；IPv6 不再单独放宽延迟上限，与 IPv4 同值。
2. **下载失败不再算成功**：HTTP 429、其它非 2xx，或不足 4096 字节，都判失败并写明原因。
3. **域名检测 421 与失败提示**：域名检测遇 HTTP 421 判失败；全部节点未通过时结果页写「域名检测失败，测速未开始」并给出下一步建议。
4. **失败节点保留、原因准确**：下载失败的节点保留卡片并标「未达标」或失败原因，失败轮只写该轮真实原因。
5. **停止测速保留结果**：点「停止」后筛选页不再把已通过节点数清成 0，第一轮结果与统计留在页面。
6. **评分刷新与页签切换**：修复多轮卡片评分不刷新，以及底部页签偶发点一次不切页。
7. **导出可读性**：失败节点不再导出 0 分 / 0 速度；CSV 把「成功轮数」「设定轮数」拆成两个整数列，避免 1/1 被 Excel 当成日期。
8. **补齐候选网段**：补上此前整段遗漏的 `104.24.0.0/14`（1024 个 /24）。
9. **预检失败有说明**：质量预检失败时说明卡在哪一步、为什么没通过，进度不再一直挂着。

## 安装

- debug HAP：`hdc install CFLark-Harmony-1.4.5-debug.hap`。
- release App Pack 发布时改名为 `CFLark-Harmony-1.4.5-app-release.app.hap`，拖入 Hokit 即可安装（Hokit 认 `.app.hap` 后缀）。
- 两个包均为未签名构建：侧载生态（Hokit、轻启、Hapkit、小白盒子等）会在安装时自动重签，无需自带签名。
