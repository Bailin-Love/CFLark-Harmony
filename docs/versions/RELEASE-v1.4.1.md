# CFLark v1.4.1 更新说明

- 版本号：1.4.1（versionCode 1004001）
- 日期：2026-10-29
- 状态：**已发布到 GitHub Releases（tag `v1.4.1`）**
- 基线：v1.4.0

## 新增

1. **中英文双语**：设置页可选择「跟随系统 / 简体中文 / English」，默认跟随系统（系统为英文时用英文，其他语言回退简体中文）；切换后立即生效，无需重启，不改动任何用户数据。
2. **设置页改为分类入口 + 详情页**：外观与主题、沉浸材质与光感、订阅与上传、运行与网络、关于与更新、诊断与调试；详情页有返回按钮，返回时恢复原滚动位置，宽屏下自动分两栏。
3. **关于页新增「检查更新」**：读取本仓库 GitHub Releases，显示当前版本、最新版本、发布时间与摘要，并给出「查看详情」入口；发布包是否存在（是否附带鸿蒙安装包）会如实说明，不会自动下载或覆盖安装。
4. **新增「更新日志」页**：按版本列出真实变更条目（新增 / 优化 / 修复）。
5. **升级后说明弹窗**：升级到新版本后首次启动弹一次「本次更新了什么」，确认后记录已展示版本，之后不再打扰；首次安装不弹，降级时只同步记录不弹。
6. **关于页新增两份声明**：参考项目说明（不包含从其他仓库复制的源代码）与 AI 辅助开发声明。

## 优化

1. **扫描页底部空白修复**：内容容器原本同时使用了 `pageBottomPad()` 内边距与固定高度的占位 `Column`，导致底部出现近三分之二屏的空白；去掉重复占位后只保留悬浮导航与手势区所需间距。
2. **底部导航选中态与手势切换同步**：选中态改为以「真正切换生效」的回调为准（`onChange`），手势拖动后回弹不再出现高亮停在错误页签的问题；未关闭动画，也未禁用滑动。
3. **新装默认 Ping 次数改为 1**（此前为 2）；已保存过自定义值的用户保持原值不变。

## 修复

1. 修复关于页按钮重叠：项目主页、检查更新、更新日志、诊断入口不再互相覆盖。
2. 修复英文界面下若干标题与按钮重叠（扫描页「快速筛选参数 / 应用建议」、筛选页「第一轮通过 / 开始测速」）。
