# CFLark v1.4.3 更新说明

- 版本号：1.4.3（versionCode 1004003）
- 日期：2026-10-31
- 基线：v1.4.2

## 面向用户的变化（相对 1.4.2）

### 新增

1. **自定义背景角标**：上传过图片后，该格左下角显示「● 自定义」，与 7 张内置预设一眼区分。
2. **致敬与致谢**：声明页新增一段，注明外观风格与玻璃材质思路借鉴了开源项目 OpenAuthenticator（作者 mroble，https://atomgit.com/mroble/Authenticator），并得到作者在实现思路上的指导。

### 优化

1. **预设背景换图**：第 3、5、7 张分别换成彩球、罗盘、蒲公英，并按手机竖屏 3:4 重新裁切；预设缓存带版本号，升级后自动换成新图，无需重选。
2. **悬浮件与卡片同材质**：右上角深浅色按钮、右下角置顶按钮改用与卡片同一套材质链（同渐变 / 模糊 / 描边 / 阴影），拖动「卡片通透度」时同步变化。
3. **升级说明弹层宽度**：最宽 460vp、左右各留 24vp，手机 / 平板 / 电脑均为居中卡片，不再顶满屏幕。

### 修复

1. **自定义背景换图必须重启**：每次选图存为带时间戳的新文件，立即生效，并清理同模式旧图。

## 未验证 / 已知限制

- 自定义背景「选图 → 再换一张」的完整链路：模拟器图库为空（系统仅提供「安全访问所选图片」，无照片可挑），逻辑已改为新文件名 + 目录扫描，需在有图库的真机确认一次。
- 预设换图只验证了手机端整屏效果，平板 / PC 走同一套渲染路径。
- 升级说明弹层本次用测试构建强制打开验证宽度，正式包中仍只在版本升级后触发。
