# CFLark v1.4.0

本次更新对应用外观体系做了系统性改造（对标 OpenAuthenticator 源码），并修复了一批布局与状态问题。

## 外观与材质
- 接入华为 HDS 沉浸光感：全局开关、材质类型（自适应 / 沉浸 / 无材质）、材质等级（自适应 / 精致 / 柔和 / 平滑），卡片统一材质表面。
- 6 套主题色（柠檬黄、奶油黄、鼠尾草绿、雾霾蓝、灰豆沙粉、清透炭黑），按钮、选中态、强调文字同步跟随。
- 背景图：7 张预设 + 图库自选 + 「无」图块；新增背景模糊程度、明亮程度滑杆；支持全局二级页面背景开关。
- 颜色模式支持 深色 / 浅色 / 跟随系统，状态栏与系统手势区配色同步。

## 悬浮导航栏
- 改为 HDS 悬浮胶囊（HdsTabs + barFloatingStyle.systemMaterialEffect）。
- 位置与尺寸对齐系统「联系人」胶囊：高 56vp、底距 28vp；胶囊宽度按设备自适应（平板 400vp）。
- 高亮胶囊跟手拖动（responsiveSpringMotion）、轻微拉伸形变、松手弹簧回弹；切页与左右滑动时即时换色。
- 拖动/点击时高亮胶囊自带主题色发光，离手立即淡出，不再有常驻光斑。
- 修复深色模式下导航发白、底部亮带（HDS gradientMask 默认遮罩导致）。

## 滚动边缘虚化
- 四个页面的 Scroll 改用 linearGradientBlur，替换旧的 16/12 层 backdropBlur 条带与蒙层（顶部 118vp、底部 106.7vp），标题与导航保持清晰。

## 页面与布局
- 卡片统一 16vp 内边距与圆角/描边/阴影；修复内容贴边、卡片被内容撑开、右列被顶部操作区顶出视口等问题。
- 平板三列等宽（按窗口宽度计算）；运行日志卡限高 520vp；执行进度条归位到运行日志列顶部。
- 筛选页 / 测速页在平板上居中限宽 900vp，导出按钮回到内容区。
- 测速结果卡、进度行与扫描页卡片样式统一。

## 功能改进
- 质量预检进度条：进度 = 合格数 / 目标数；达标后把并发溢出的多余合格节点裁到目标数，不再出现 130% 这类越界。
- 「应用建议」IPv4/IPv6 统一：采样 3000、并发 30、延迟上限 300ms、Ping 1 次、合格速度 0.1MB/s。
- 默认参数同步为：采样数 3000、并发线程 30。
- 自定义来源支持 链接导入 / 文件导入 / 文本粘贴；来源下拉与导入弹窗改为同源材质样式。

## 启动与图标
- 全新应用图标（AppScope layered icon：渐变波纹底 + 飞鸟/地球/小球前景），修复前景与背景重复导致的「重影」。
- 启动窗口：深色 #0B0B12 / 浅色 #F2F5FA，图标满幅居中；应用内首帧改为 140ms 淡入，取消整屏缩放。

## 问题修复
- 修复深色模式悬浮导航发白与屏幕底部亮带。
- 修复预检进度条分母错误（曾出现 130%）。
- 修复平板布局破坏（Row 子列同时使用 width(100%) 与 layoutWeight）。
- 修复卡片修饰链错挂导致的布局异常与编译错误。
